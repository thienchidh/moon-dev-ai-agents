# 🌙 Path Migration Guide - Windows Compatibility Fix

## Overview

This project has been updated to use **relative paths** instead of hardcoded MacOS absolute paths, making it fully compatible with Windows, macOS, and Linux.

## What Changed

### Before
```python
# Hardcoded MacOS path - NOT cross-platform compatible ❌
DATA_DIR = "/Users/md/Dropbox/dev/github/moon-dev-ai-agents-for-trading/src/data/rbi"
```

### After
```python
# Cross-platform relative path - Works on all systems ✅
from pathlib import Path
DATA_DIR = Path(__file__).parent.parent / "data" / "rbi"
```

## New Utility Module: `path_utils.py`

A new utility module has been created at `src/path_utils.py` that provides convenient functions for accessing common project directories:

```python
from path_utils import get_rbi_data_dir, get_data_dir

# Get path to RBI data directory
rbi_dir = get_rbi_data_dir()

# Get path to specific data subdirectory
web_search_dir = get_data_dir("web_search_research")

# Get path to project root
from path_utils import get_project_root
project_root = get_project_root()
```

### Available Functions

- `get_project_root()` - Returns project root directory
- `get_data_dir(subdir=None)` - Returns data directory or subdirectory
- `get_agents_dir()` - Returns agents directory
- `get_scripts_dir()` - Returns scripts directory
- `get_strategies_dir()` - Returns strategies directory
- `get_rbi_data_dir()` - Returns RBI agent data directory
- `get_chat_agent_data_dir()` - Returns chat agent data directory
- `get_web_search_data_dir()` - Returns web search research data directory
- `get_arxiv_data_dir()` - Returns Arxiv papers data directory
- `get_code_runner_data_dir()` - Returns code runner data directory
- `get_private_data_dir()` - Returns private data directory
- `get_rbi_pp_multi_data_dir()` - Returns RBI PP Multi data directory
- `ensure_dir_exists(path)` - Creates directory if it doesn't exist

## Migration Guide for Custom Code

If you have custom scripts or agents that use hardcoded paths, here's how to update them:

### Option 1: Using path_utils (Recommended)

```python
# Add to top of your file
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent.parent))
from path_utils import get_data_dir, get_rbi_data_dir

# Use in your code
data_file = get_rbi_data_dir() / "BTC-USD-15m.csv"
output_dir = get_data_dir("my_agent")
```

### Option 2: Using pathlib directly

```python
from pathlib import Path

# Get project root (src/agents -> src -> project_root)
project_root = Path(__file__).parent.parent.parent

# Build paths relative to project root
data_file = project_root / "src" / "data" / "rbi" / "BTC-USD-15m.csv"

# Or relative to current file
data_file = Path(__file__).parent.parent / "data" / "rbi" / "BTC-USD-15m.csv"
```

### Option 3: Using os.path (Legacy)

```python
import os

# Get directory of current file
current_dir = os.path.dirname(os.path.abspath(__file__))

# Build relative paths
data_dir = os.path.join(current_dir, "..", "data", "rbi")
data_file = os.path.join(data_dir, "BTC-USD-15m.csv")
```

## Common Issues

### Import Error: `ModuleNotFoundError: No module named 'path_utils'`

**Solution**: Make sure you're running scripts from the project root, or add:
```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent.parent))
```

### Path Not Found

**Solution**: Verify the directory structure is correct. The project should have:
```
moon-dev-ai-agents/
├── src/
│   ├── agents/
│   ├── data/
│   ├── scripts/
│   ├── path_utils.py
│   └── ...
└── ...
```
